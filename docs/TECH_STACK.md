# Suggested technical stack

## Recommended start

- React
- Vite
- TypeScript
- Basic CSS or Tailwind

## Why this stack

- Fast setup for a short hackathon build
- Easy local demo
- Clear separation of UI, state, and structured edit logic

## Optional later integration

- Gemini API for request interpretation
- Google AI integration if needed for natural-language-to-plan conversion

## Keep implementation lean

- do not build a full production video editor
- focus on one strong workflow with a visible AI contribution

# Demo script

## 30-second summary

"This app turns a plain-language request into a safe, structured edit plan for a video, previews the result, and lets the user undo the entire AI action."

## Suggested live flow

1. Open the app.
2. Select a sample video or mock timeline.
3. Enter a request such as: "Trim the first 10 seconds and keep the key answer with a title card."
4. Show the AI-generated structured plan.
5. Show the preview result.
6. Click keep or discard.
7. Show the undo action working.
8. Optional: enter an invalid request and show the validation error.

## Key talking points

- the AI does not directly manipulate the video
- it produces structured edit instructions
- edits are validated before application
- the user stays in control
- one-step revert makes the flow safe

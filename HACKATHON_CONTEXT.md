# Hackathon context

## Event

Hacktoberfest Hack Day 2026
React Hyderabad × MLH × DEV

## Challenge selected

Build on elah

## Goal

Produce a working, focused AI editing prototype that demonstrates a complete AI-assisted editing workflow.

## Requirements summary

The solution should be:

- AI-powered
- browser-based
- workflow-driven
- previewable
- reversible
- structured and validated

## Demo story

"This app helps a creator turn a plain-language editing request into a safe, previewable, reversible video cut."

## Perfect demo sequence

1. User enters a request.
2. AI generates a structured edit plan.
3. App validates the plan.
4. Preview appears in editor.
5. User chooses keep, reject, or refine.
6. User can undo the entire AI change.
7. Show an invalid request being rejected cleanly.

## Implementation philosophy

- AI writes structured operations, not direct file manipulation.
- UI remains fast and understandable.
- Validation is explicit and simple.
- Keep the first version useful, not broad.

## Risk management for this build

- do not chase feature breadth
- prioritize one polished workflow
- use mock or local sample assets if needed
- ensure final demo is reliable even if AI output varies

## Project goal

Build a narrow, demo-friendly AI video editing workflow that:

- takes a natural-language editing request,
- converts it into a structured edit plan,
- validates the plan,
- previews the result,
- lets the user accept, reject, or refine it,
- supports one-step revert of the full AI action.

## Recommended build direction

Use a lightweight "highlight cut" workflow for a talking-head video:

- user asks for a shorter highlight version,
- the app turns the request into safe edit operations,
- the app previews the result,
- user can keep or undo the change.

## Challenge fit

This repo is aligned with the Elah challenge in the project brief:

- Build on Elah
- AI-powered browser-based video editing
- Structured editing operations instead of direct DOM/pixel manipulation
- Validated plan + preview + keep/discard/refine
- One-step reversal of the AI edit
